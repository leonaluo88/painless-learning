# 视觉参考（ui-kit）

用户认可的样式来源：2026-11-14 那版 MAST90104 期末冲刺页（Claude 做）。这里把它拆成**可以直接复用的令牌、骨架和组件**，不依赖那门课的数据。

配套文件：`references/ui-kit.css`（可以整块贴进 `<style>`，也可以只取需要的部分）。

> **这是参考，不是模板。** 用户原话：*「所有东西全部按照这个格式或者构架的话，很瘆人，而且学习的东西多了，容易记不清楚它在哪个网页的哪个部分。但如果不同的课用不同的颜色或者主题，潜意识就会比较容易区分。」*
>
> 所以：**A 类（字号层级、行宽、等宽数字、表格包壳、焦点态、断点、不用楷体）照做**——这些是“读起来不费劲”的原因，跟配色无关；**B 类（主题色）每门课必须换**——按课程代码定一个色相写进 `theme`，同一门课沿用，不同课不撞色；**C 类（布局骨架、内容块形状、背景层数、组件取舍）完全自由**——按这门课的信息形态选，别为了统一把每个页面做成同一个样子。
>
> 只有**公式的表述方式**要照抄，见 SKILL.md 第七节 D 小节。

## 一、为什么它看起来舒服（先理解，再套用）

不是配色好看，是四条纪律：

1. **只有一种底色对比**：浅灰页面（`--paper`）+ 纯白卡片（`--card`）。全站没有第三种背景，所以任何白块都自动被读成“内容单元”。
2. **只有一种强调色**：深蓝 `--accent` 只出现在“可点 / 当前 / 定义框边框”三种地方。颜色不是装饰，是“这里能点”的信号。
3. **高亮只给核心**：黄色 `--mark` 只用于“核心知识点”和“荧光笔标记”，一屏里出现不超过 3 处。用多了就不叫高亮。
4. **字号只有五级**：20 / 16 / 15 / 13.5 / 12.5。没有 11px 的正文，没有 17px 的标题。层级靠**颜色变灰**而不是靠字号乱跳。

> 一句话：**信息密度高，但视觉噪音低**。密度靠“把说明文字降级变灰”，不靠“把字缩小”。

## 二、令牌（结构色照抄，主题色每课换）

| 令牌 | 浅色 | 深色 | 用在哪 |
|---|---|---|---|
| `--paper` | `#F3F5F8` | `#11151B` | 页面底色 |
| `--card` | `#FFFFFF` | `#181E26` | 所有卡片 |
| `--ink` | `#17202B` | `#E5EAF0` | 正文（**不用纯黑**） |
| `--muted` | `#5B6672` | `#9AA5B1` | 说明、表头、次要信息 |
| `--line` | `#D6DCE3` | `#2A333E` | 所有边框和分隔线 |
| `--accent` | `#1F4E8C` | `#86B4EE` | 链接、选中、定义框 |
| `--mark` | `#FFE16A` | `#7A6620` | 核心标记（荧光笔） |
| `--good` | `#2E7D4F` | `#5FC08A` | 已掌握、正确 |
| `--warn` | `#B86A00` | `#E3A048` | 考点、需注意 |
| `--bad` | `#B23A3A` | `#E07070` | 陷阱、错误 |
| `--r` | `8px` | — | 圆角，全站统一 |

**四套字体，各有分工，不能混用**：

| 字体 | 用在哪 | 为什么 |
|---|---|---|
| `--font-body` IBM Plex Sans + 苹方 | 正文、标题、按钮 | 中英混排时数字和字母不会歪 |
| `--font-mono` IBM Plex Mono | 编号、分数、计时、代码、R 输出 | 数字等宽，列能对齐 |
| `--font-en` Georgia / Times | 英文原题、英文答案 | 和中文正文拉开，一眼看出“这是要抄到卷子上的” |

> **不要用楷体**。2026-11-14 试过用楷体做“人话解释框”，用户评价“丑的要死”，大屏上像旧书、手机上更糊。要区分补充说明，只降颜色（`color-mix(in srgb,var(--ink) 78%,var(--paper))`）+ 一条左细线就够了。

**颜色分两类，处理方式不同**：

- **结构色不许动**：`--paper` / `--card` / `--ink` / `--muted` / `--line`。它们决定“白卡片浮在浅灰底上”这个基本关系，改了会让内容单元的边界消失。深色模式同理（`#11151B` / `#181E26`）。
- **主题色每门课必须换**：`--accent`（主色）、`--mark`（荧光笔）、以及由主色派生的模块配色。这是用户能“潜意识认出这是哪门课”的唯一线索。

**怎么换主题色**（三步，不要重新调一套完整配色）：

1. 按课程代码定一个色相，写进 `course.json`：
   ```json
   "theme": {"hue":"265", "name":"靛紫", "accent":"#4A3B8C", "mark":"#FFE16A"}
   ```
   同一门课的所有网页**沿用同一个值**，不要重抽；不同课之间**不要撞色**。参考分配：数学/统计 215 深蓝、线代/抽象数学 265 靛紫、编程/数据 165 墨绿、语言/人文 25 赭橙、生物/医学 340 洋红。
2. 只改 `--accent` 和它的深/浅两档（`--accent-soft` 用 `color-mix(in srgb, var(--accent) 10%, #fff)` 派生，不要手写第二个色值）。
3. 模块配色用同一色相的不同明度生成（12 档），**不要引入第二个色相**。语义色 `--good` / `--warn` / `--bad` 保持不动——红绿橙的语义跨课程通用，换了反而看不懂。

**换完必须检查**：`--accent` 仍然只出现在“可点 / 当前选中 / 定义框边框”三种地方；`--mark` 一屏仍然 ≤3 处；背景仍然只有 `--paper` 和 `--card` 两层。**主题色换的是色相，不是用法。**

## 三、骨架（三种，够用）

### 3.1 课堂：左栏 270 + 主区

```html
<div class="lgrid">
  <aside class="lside"> …单元 / 课 / 步骤三层… </aside>
  <section class="stepcard"> …一步讲解… </section>
</div>
```

左栏三层，层级一眼分清：单元是可折叠标题条（`details.grp`）→ 课是一行带模块色点 → 步骤用 `border-left` 竖线串起来的小圆点。**只默认展开当前单元**。

### 3.2 地图：左图 + 右栏 360

```html
<div class="mapgrid">
  <div class="graphbox"><svg>…</svg><div class="zoom">…</div><div class="hint">…</div></div>
  <aside class="panel card"> …详情… </aside>
</div>
```

右栏 `position:sticky`，高度 `calc(100vh - 110px)`，**常驻不浮层**。图区高度 `min(72vh,760px)`。

### 3.3 单栏：考情 / 真题 / Cheat Sheet

`.wrap` 限宽 1320，内容块限宽 78ch。表格外面套 `.tblwrap`（横向滚动 + 边框 + 圆角）。

## 四、组件配方

### 4.1 内容块（讲解页的核心，六种形状各不相同）

```html
<div class="blk def"><b>定义 · M6 p.22</b> …公式… </div>
<div class="blk plain">补充说明：只降颜色 + 左细线，不换字体</div>
<div class="blk ex"><b>例</b> …</div>
<div class="blk exam"><b>考点</b> 样卷 Q2(a) 就这么问</div>
<div class="blk trap"><b>陷阱</b> 很多人以为…</div>
<div class="blk write"><b>照这个写</b><div class="en">…English…</div><div class="zh">中文解释</div></div>
```

**规则**：`def` 是蓝框实线、`ex` 是灰虚线、`exam` 是橙色左粗条、`trap` 是红色左粗条、`plain` 只有一条灰细线 + 稍浅的文字颜色。**不用底色区分**（除了 `write` 用浅灰底），因为底色一多就花。

标题（`<b>`）字号 12.5px 且带颜色，正文 15px。这样“标签”和“内容”不会抢。

### 4.2 知识点 chip（编号 + 短名，可点）

```html
<span class="pchip t3" data-id="rank"><span class="nn">2</span>秩</span>
```

- 核心点用 `box-shadow:inset 0 -3px 0 var(--mark)` 加一条底部荧光条，**不换底色**——换底色会和“已掌握”的绿底撞。
- 已掌握时 `data-s="2"` → 绿底白字。
- 编号用等宽小字、灰色，不抢短名。

### 4.3 题卡（全站只有一种）

```html
<div class="qcard">
  <div class="qh"><span class="tier t3">核心</span> <span class="qchip">Q1(a)</span> 2 分 · 建议 3.6 分钟
    <span class="sp"></span><label class="mk"><input type=checkbox> 已掌握</label></div>
  <div class="qz">题干…</div>
  <div class="opts"><button class="opt">A …</button>…</div>
  <div class="fb ok">对。因为…</div>
</div>
```

选项是**整行按钮**（`flex-direction:column`），不是 A/B/C/D 四个小方块——长题干时整行更好点，手机上也不会挤。

### 4.4 表头吸顶 + 数字等宽

```html
<div class="tblwrap"><table><thead><tr><th>小问</th>…</tr></thead><tbody>…</tbody></table></div>
```

`th` 用 `position:sticky;top:0`，`td.num` 用等宽 + `tabular-nums`。长表格滚动时表头不丢。

### 4.5 计时胶囊

```html
<div class="stimer">⏱ 本步 <b>00:15</b> · 本课 <b>00:42</b></div>
```

绝对定位在步骤卡右上角，`background:var(--paper)` 圆角 99px。**不要做成灰色小字**（踩过的坑）。

### 4.6 提示条 / 撤销条 / 弹窗

- `.tipline`：浅蓝底一行，右侧 ×，每个板块第一次打开时出现。
- `.utoast`：深色条 + 一个「撤销」按钮，8 秒后自动消失。
- `.modal`：点遮罩关闭，`.cap` 里放标题和关闭按钮。

## 五、排版细则（这些细节决定了“专业感”）

| 规则 | 值 | 原因 |
|---|---|---|
| 正文行高 | `1.6` | 中文 1.5 偏挤，1.8 偏散 |
| 正文宽度 | `max-width:78ch` | 超过约 80 字符，眼睛回行会丢行 |
| 引导语宽度 | `max-width:72ch` | 比正文再窄一点，读起来像“导语” |
| 标题换行 | `text-wrap:balance` | 避免最后一行只剩一两个字 |
| 数字 | `font-variant-numeric:tabular-nums` | 分数、时间、编号纵向对齐 |
| 表格单元格 | `padding:6px 9px` | 比默认的 8px 更紧凑，密而不挤 |
| 段落间距 | `margin:12px 0` | 块与块之间留一口气 |
| 列表 | `padding-left:1.5em`，`li` 间距 4px | 中文列表默认太贴 |
| 罗马序号 | Times New Roman，`.84em` | (I)(II)(III) 用衬线体才像试卷 |
| 行内公式 | 不额外加间距 | MathJax 自带 |
| 独立公式 | `margin:.6em 0` | 上下各半行，不要 1em |
| 焦点态 | `outline:2px solid var(--accent)` | 键盘可用，不要 `outline:none` |
| 安全区 | `padding:env(safe-area-inset-*)` | iPhone 刘海屏 |
| 减弱动效 | `prefers-reduced-motion` | 无障碍 |

## 六、响应式（手机不是"缩小版电脑"）

用户的原话：*「换手机排版和电脑排版的时候可能会有点不舒服以及看得比较费劲」*。所以这一节和上面同等重要，不是附注。

**断点只有两个**：`900px`（所有双栏塌成单栏）、`700px`（手机专用放大与重排）。不要再加 1024、768、480 这些。

### 6.1 手机上要改的五件事

| # | 改什么 | 怎么改 | 不改会怎样 |
|---|---|---|---|
| 1 | **字号整体上浮一档** | `body{font-size:16px}`，`.small/.lede/.why` 13.5px，`.nn/.pchip` 12.5px，`h2` 19px | 12.5px 在手机上要眯眼；这是"看得费劲"最主要的原因 |
| 2 | **可点元素够大** | `.btn` 最小 38px 高、`.opt` 44px、`.pchip` 30px、`.zoom .btn` 40×40；`.stepnav .btn{flex:1}` 各占一半 | 手指点不中，误触，来回点 |
| 3 | **表格换形态** | 不再是横向滚动，改成"每行一张小卡"：`thead` 隐藏，每个 `td` 前用 `data-label` 显示列名 | 横向滚动在手机上极难用，用户根本不会滚 |
| 4 | **顶栏收起来** | 主板块标签 `order:3;width:100%` 独占一行横向滚动；`.brand` 隐藏；次要按钮加 `.hide-m` | 顶栏挤成三行，占掉半屏 |
| 5 | **间距收紧** | `.wrap` padding 14px；`.card` 12/13；`.blk` 取消 `max-width` | 手机上左右各留 18px 白边，正文只剩 340px |

### 6.2 表格转卡片：必须给 `td` 加 `data-label`

```html
<td data-label="分值" class="num">7</td>
```

CSS 里靠 `td::before{content:attr(data-label)}` 把列名显示出来。**没有 `data-label` 的表格，在手机上会变成没有列名的数字堆，看不懂。** 这是硬要求，写表格时就要带上。

### 6.3 公式：永远不要撑破容器

```css
.mjx-container[display="true"]{max-width:100%;overflow-x:auto;overflow-y:hidden}
```

桌面也会溢出（长矩阵、长推导），不只手机。横滚比裁掉好。

### 6.4 图（拓扑图）在手机上

- 高度 `58vh`、最小 340px——比桌面矮，因为下面还有右栏内容要读。
- `touch-action:pan-y`：横向拖平移图，竖向滑仍滚页面。
- 缩放按钮 40×40（拇指尺寸），`.hint` 那行提示字直接隐藏（它挡图）。
- 右栏 `position:static`，排在图下面，不浮层。

### 6.5 验证方法（必须做）

```bash
# 桌面
chrome --headless --window-size=1440,1500 --screenshot=desktop.png file://…/index.html
# 手机：用 iframe 套 390px，因为 headless Chrome 有最小窗口宽度，直接 --window-size=390 不生效
```

`phone-frame.html`：

```html
<body style="margin:0;background:#8a8f96;display:flex;justify-content:center">
  <iframe src="index.html" style="width:390px;height:1780px;border:0"></iframe>
</body>
```

**坑**：直接 `--window-size=390,1800` 截图会得到 485px 宽的页面被裁成 390px 的图，看起来像"右侧被切掉"，其实是假的。用 iframe 才准。

## 七、常见做坏的方式（对照自查）

- ❌ 用了三种以上背景色（白卡 + 浅蓝卡 + 浅黄卡）→ 页面变花
- ❌ 主色被当成装饰色，标题、图标、边框到处是蓝 → “能点”的信号失效
- ❌ 荧光笔标了十几个点 → 等于没标
- ❌ 说明文字用 11px 而不是“13.5px + 灰色” → 读不清，且层级乱
- ❌ 卡片圆角 4 / 6 / 8 / 12 混用 → 显得随手拼的
- ❌ 表格没有 `overflow-x:auto` → 手机上撑破页面
- ❌ 双栏在 900px 以下不塌成单栏 → 手机上左栏只剩 100px
- ❌ 数字不用等宽字体 → 分值列对不齐
- ❌ 正文宽度铺满 1320px → 一行 40 个字，眼睛回行丢行
